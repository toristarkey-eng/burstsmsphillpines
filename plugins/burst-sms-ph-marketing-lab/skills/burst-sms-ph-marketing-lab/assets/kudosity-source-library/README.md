# Kudosity messaging image library

Prepared 10 October 2026. Twelve existing images sourced from Kudosity marketing pages, supplied as individual PNG files with unchanged SVG masters where available. This is a curated source library, not newly invented product UI or blanket approval for publication.

## Usage

- Place the images in brand-compliant creative using Noto Sans, navy #002A66 and violet #4C23CC. Use the exact supplied primary wordmark separately when branding an ad.
- PNGs preserve original transparency where it exists. Some original artwork has an intentional background. Do not describe every PNG as a cutout.
- Do not enlarge raster assets beyond their source dimensions. SVG masters can scale. Keep complete message text and any relevant qualifiers visible.
- 01 is a historical platform overview. 02 predates the April 2026 Senders redesign. 04 uses old phone interfaces and legacy support text. These are references, not current product UI for external campaigns. Replace these three with current approved captures before publication.
- Message brands, verification marks, offers and customer details are illustrative. They do not establish a real customer relationship or imply every sender receives verification.
- Channel availability, message types, consent, template rules and sender requirements must be checked for the intended market and campaign. No availability or performance claims are encoded as promises in this collection.
- 11 is an existing RCS illustration, not a certification or security guarantee. 12 is an abstract published composition, not an actual UI capture.
