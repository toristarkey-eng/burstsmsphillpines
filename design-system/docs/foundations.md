# Burst SMS Philippines visual foundations

## Design intent

The system combines Burst SMS recognition with Kudosity's current platform language. It should feel local, modern, useful, and human. Work should look at home on `burstsms.com.ph` while remaining unmistakably Burst SMS.

## Colour roles

| Token | Value | Role |
| --- | --- | --- |
| Navy | `#002A66` | Headings, trust, dark surfaces |
| Violet | `#4C23CC` | Primary action and expressive emphasis |
| Cyan | `#00AEC4` | Burst recognition, links, communication motifs |
| Burst blue | `#005677` | Secondary emphasis and legacy compatibility |
| Cloud | `#F4F5FF` | Section surfaces |
| Ink | `#121217` | Body copy |
| Blush | `#FFB3B3` | Human warmth and small accents |
| Mint | `#0AD17A` | Positive status and send moments |

Navy, violet, white, and cloud should occupy most of a layout. Cyan provides the Burst connection. Blush and mint should remain accents.

## Type

Noto Sans is the digital typeface because it matches the live hybrid experience and supports a wide range of characters. Helvetica Neue remains the compatibility choice for legacy brand files and presentations.

- Display: medium, tightly set, usually 48–80px on desktop.
- Section headings: medium, 36–52px on desktop.
- Body: regular, 16–20px with 1.5 line height.
- Controls: semibold, 14–16px.
- Labels: semibold, 12–14px with modest letter spacing.

## Composition

Use generous white space, a clear reading order, and one dominant idea per section. Use rounded geometry to echo speech bubbles, but avoid turning every element into a card. Product UI fragments and message bubbles should support the message rather than become decoration.

## Photography and illustration

Prefer natural, contemporary images of Philippine professionals and customers in credible contexts. Show the person as an active participant, not a generic stock-photo prop. Avoid tourist clichés, flags as decoration, and forced cultural shorthand.

Illustration should use simple communication cues, soft layered circles, and product-relevant details. Keep effects restrained.

## Motion

Motion should clarify sequence and reinforce conversation. Use short fades, upward reveals, message sends, and cursor or typing cues. Avoid excessive bouncing, spinning, or motion that delays the next action. Respect `prefers-reduced-motion`.
